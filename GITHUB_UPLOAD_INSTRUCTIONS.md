# Nexora — GitHub upload

Important: upload the **contents of this ZIP** to the root of the GitHub repository. Do not put the files inside another folder.

The GitHub root must directly contain:

- `app/`
- `lib/`
- `public/`
- `package.json`
- `next.config.ts`
- `tsconfig.json`

Inside `app/`, `page.tsx` and `layout.tsx` must be present.

For Vercel, use **Root Directory: `./`** when `app/` is directly visible in the repository root.

This package is Nexora-branded and includes the Nexora logo, 15-language UI, Supabase integration, customer/professional accounts, messaging, favorites, pins, reviews, bookings, premium/admin tools, emergency numbers, privacy and terms pages.
